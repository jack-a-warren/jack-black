# jack-black

A textual blackjack program

This program simulates the casino game: blackjack.

## Features

Player can bet chips which pay 2 to 1 for a win.

The program implements all fundamental aspects of blackjack: hitting, standing,
doubling down, and surrendering.

Program populates a "virtual deck" with cards from which it draws, each draw
thus affects the probability of each card value in future draws. This is the
principle behind card-counting and is simulated so that card counting becomes
possible and the program may be used as a tool to practice it.
